# RouterForge 0.15.0 Beta 6

В этом обновлении мы сосредоточились на стабильности работы модулей, исправлении ошибок и улучшении взаимодействия с накопителями, сетевыми хранилищами и Центром приложений.

## Исправления и улучшения

**Storage Doctor и SMART**
- Настройки типа подключения SMART теперь сохраняются отдельно для каждого накопителя.
- Исправлено отображение устаревших SMART-данных после замены USB-диска.
- Улучшена привязка истории температур и состояния накопителя к конкретному устройству.
- Исправлены ошибочные температурные предупреждения и отображение результатов диагностики.
- Улучшена работа с накопителями, не предоставляющими уникальный идентификатор.

**Системные журналы и SMB/NAS**
- Улучшено автоматическое восстановление подключения к сетевому хранилищу.
- Добавлено предупреждение, если NAS подключён, но запись журналов недоступна.
- Восстановление подключения учитывает работу syslog-ng и не прерывает активную запись журналов.

**Резервное копирование и восстановление**
- Улучшено восстановление конфигурации при превышении ограничений Config Vault.
- Перед восстановлением сохраняется резервная копия текущей конфигурации.
- Локальные настройки подключения SMB сохраняются при восстановлении из резервной копии.

**Центр приложений**
- Добавлена дополнительная проверка зависимостей перед удалением пакетов Entware.
- Исправлено определение результата обновления: Центр приложений проверяет фактически установленную версию.

**Интерфейс и «Что нового»**
- Кнопка «Что нового» плавно подсвечивается, когда опубликован непрочитанный выпуск для установленного канала Core.
- Для Beta Core сначала открываются бета-патчноуты, для Stable Core — стабильные релизы. Ручное переключение остаётся доступным.
- После успешного просмотра новых заметок подсветка исчезает; прочитанная версия запоминается в браузере.
- Добавлено предупреждение, если браузер не смог сохранить настройки.
- Улучшено отображение ошибок SMART для отдельных накопителей.

## Важно

- Проверка SMART по-прежнему запускается только по запросу пользователя.
- Восстановление конфигурации не перезапускает службы автоматически.
- DNS Router остаётся экспериментальным модулем. Перед изменением рабочих DNS-настроек рекомендуется сохранять конфигурацию.
- Для автоматического обнаружения новых патчноутов нужен доступ RouterForge к каталогу выпусков GitHub. Подсветка работает после установки Core с этим обновлением.

Спасибо всем, кто тестирует RouterForge и помогает делать его стабильнее!
