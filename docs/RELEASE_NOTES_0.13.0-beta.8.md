# RouterForge 0.13.0 Beta 8

Beta 8 добавляет добровольное исключение проверки защищённости соединения с CrowdSec LAPI из общего статуса CrowdSec Manager. Исправление P3 прошло GitHub CI на ветке dev.

## 🔧 CrowdSec Manager

- В настройках Windows LAPI появилась опциональная кнопка **«Игнорировать TLS»**.
- Действие требует явного согласия пользователя с риском незашифрованного HTTP-соединения или TLS без проверки сертификата.
- Согласие сохраняется отдельно от конфигурации Bouncer, привязано к адресу LAPI и может быть отменено. При смене адреса прежнее согласие не действует.
- При активном исключении предупреждение о риске остаётся видимым. Если остальные проверки проходят, защита может отображаться как `ACTIVE · TLS RISK`.
- Исключение влияет только на общий статус RouterForge: оно **не отключает TLS**, не изменяет сертификаты, ключи и конфигурацию Bouncer, не перезапускает службы.
- Проверки работающего Bouncer, ipset, правил `FORWARD/DROP`, NDM hook и доступности LAPI остаются обязательными.
- Сохранены улучшения P1/P2 из Beta 7 для пользовательских NDM hook и динамической позиции цепочки CrowdSec.

## 📦 Поддерживаемые архитектуры

- `aarch64-3.10` — ARM64.
- `mips-3.4` — MIPS.
- `mipsel-3.4` — MIPSEL.

Выпуск включает десять компонентов на архитектуру — всего 30 IPK, отдельные индексы и установочные скрипты. Версия согласованной матрицы: `0.13.0~beta.8`.

## ⚠️ Обратите внимание

- Пользователь принимает риск незашифрованного соединения самостоятельно; исключение предупреждения не повышает безопасность передачи данных.
- Это тестовый релиз; аппаратная проверка новой опции на конфигурации пользователя ещё предстоит.
- Проблема DNS Manager после холодного запуска Keenetic Giga KN-1010 продолжает исследоваться и **не заявляется исправленной**.
- Stable не меняется; обновления не устанавливаются автоматически.
