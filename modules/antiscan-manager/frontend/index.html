МОБИЛЬНЫЕ СЕТИ

Почему мобильный адрес может попасть под раздачу

1Antiscan запоминает адреса-кандидаты.
2Несколько адресов одной /24 могут накопиться за период хранения.
3После порога вся /24 попадает в ascn_subnets.
4Новый легитимный мобильный IP из этой /24 тоже оказывается заблокирован.
