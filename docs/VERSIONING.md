# RouterForge Versioning Policy

RouterForge использует `MAJOR.MINOR.PATCH` и независимое версионирование компонентов. До первого стабильного контракта `1.0.0` используются версии вида `0.MINOR.PATCH`.

## PATCH

Совместимые исправления ошибок, улучшения интерфейса, надёжности, производительности, безопасности и небольшие функции без смены архитектурного контракта.

## MINOR

Крупные новые возможности, самостоятельные модули, существенные изменения архитектуры или совместимости.

## MAJOR

`1.0.0` выпускается отдельным решением при достаточной зрелости API, установки, обновлений, восстановления и тестирования на устройствах.

## Версии компонентов

Версия выпуска RouterForge и версии отдельных пакетов могут различаться. Неизменённый компонент не получает новую версию только ради общего номера релиза.

Для предварительных OPKG-пакетов используется суффикс `~`, который сортируется ниже соответствующего стабильного выпуска.

Проверить актуальные версии можно в [GitHub Releases](https://github.com/Fifth-Ace/routerforge/releases) и Центре приложений.

Новый компонент при первом выпуске получает текущую версию Core; далее его версия развивается независимо. min_core_version отражает минимальную совместимую версию Core и не обязана совпадать с версией модуля.
