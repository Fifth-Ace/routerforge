# RouterForge 1.0.0 — первый большой релиз платформы

**RouterForge 1.0** — единая модульная веб-платформа для Keenetic / Netcraze с Entware. Вместо набора разрозненных страниц и команд — общий интерфейс для управления роутером, сетью, DNS, диагностикой и защитой.

## Возможности платформы 1.0

- **Единый Core и Центр приложений:** установка и обновление нужных модулей, управление пакетами Entware, информация о версиях, история изменений и авторизация.
- **DNS и DNS Router:** управление штатными резолверами, а также самостоятельный DNS-сервис с маршрутизацией по доменам, спискам и устройствам, защищёнными upstream, мониторингом и журналом запросов.
- **Администрирование:** файлы, процессы, службы, Entware Terminal, Keenetic NDM Console, резервные копии, syslog-ng и хранение журналов на USB или SMB/NAS.
- **Мониторинг и диагностика:** ресурсы роутера, сеть, состояние накопителей, Storage Doctor, SMART по запросу и история ошибок.
- **Сетевые инструменты:** проверка соединений, маршрутов, сетевых потоков и доступности ресурсов.
- **Безопасность и сетевой доступ:** отдельные менеджеры NFQWS, Antiscan, Port Access и CrowdSec.
- **Обновлённый интерфейс:** все 11 компонентов переведены на Svelte 5, улучшены навигация, работа с состояниями и русский/английский языки.
- **Дополнительные инструменты:** локальное профилирование Core, интеграционные карточки сторонних приложений и ссылка на браузерное расширение RouterForge Portal.

## Что изменилось после Stable 0.14.0

- **Новый DNS Router** вошёл в состав платформы: независимый DNS-сервис с UDP/TCP/DoT/DoH/DoQ, доменными списками, индивидуальными правилами устройств и управляемым DNS Gate для локальной сети.
- **DNS Router получил расширенные настройки:** IP-стратегии, проверки доступности адресов, локальные записи A/AAAA/CNAME/PTR, DNS Stamp, настройки кэша и защищённые входящие соединения с mTLS.
- **Admin получил syslog-ng:** управление системными журналами, источниками, USB и SMB/NAS из веб-интерфейса.
- **Monitoring получил Storage Doctor:** состояние физических накопителей, SMART по запросу, температуры, историю ошибок и улучшенную привязку диагностических данных к дискам.
- **Переработаны все 11 интерфейсов:** единый Svelte 5, более последовательная навигация и расширенная локализация RU/EN.
- **Укреплены резервное копирование и обновления:** защищено хранение SMB-учётных данных, улучшено восстановление конфигурации, результаты обновления проверяются по фактически установленной версии.
- **Обновлён Центр приложений:** добавлены предварительные интеграции opffk и qWDTT Server Keenetic, а также улучшены проверки действий с пакетами.
- **Улучшено окно «Что нового»:** история Stable/Beta, обнаружение непрочитанных выпусков, запоминание прочитанного и выбор канала.
- **Представлен RouterForge Server:** отдельный Linux/VPS-проект; в RouterForge добавлены закрываемое объявление, информационная карточка «В разработке» и страница будущей интеграции.
- **Добавлена ссылка на RouterForge Portal:** браузерное расширение, которое устанавливается в браузер, а не на роутер.

## Совместимость и границы

Для первого общего Stable **все 11 официальных пакетов имеют реальную версию 1.0.0**; в последующих выпусках они могут версионироваться независимо. Доступные сборки ориентированы на `aarch64-3.10`, `mips-3.4` и `mipsel-3.4`; степень аппаратной проверки зависит от архитектуры и устройства. Действия, меняющие DNS-перехват и системные настройки, требуют явного применения. RouterForge Server пока не подключается к роутеру и не управляет им удалённо — эти возможности находятся в разработке.

**Подробный перечень изменений со Stable 0.14.0** см. в полном документе выпуска.
