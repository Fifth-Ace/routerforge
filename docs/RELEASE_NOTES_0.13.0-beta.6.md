# RouterForge 0.13.0 Beta 6

Обновление Beta 6 посвящено совместимости с Keenetic, корректности отображаемых данных и работе каталога обновлений.

## 🔧 Исправления и улучшения

**DNS Manager и Keenetic Mesh**

- Улучшена устойчивость DNS Manager при холодном запуске роутера: запросы к системной службе `ndmc` учитывают её готовность после загрузки.
- Доработано обнаружение подключённых устройств в Mesh-сети. Если основной способ получения списка клиентов временно недоступен, используется резервное получение данных из ARP.
- Сохранены существующие настройки и принцип работы DNS Manager.

**Температура процессора**

- Исправлено отображение температуры Wi-Fi как температуры CPU на устройствах без доступного датчика процессора.
- Когда показания CPU/SoC недоступны, интерфейс показывает отсутствие данных вместо температуры другого компонента.
- Температуры Wi-Fi продолжают отображаться в мониторинге как отдельные датчики.

**Обновления и совместимость**

- Исправлена доступность канала Stable на архитектурах `mips-3.4` и `mipsel-3.4`.
- Добавлена периодическая фоновая синхронизация каталога релизов Core с интервалом 30 минут, в том числе без открытого веб-интерфейса.
- Фоновая проверка обновлений не означает автоматическую установку пакетов.

## 📦 Поддерживаемые архитектуры Beta 6

- `aarch64-3.10` — ARM64.
- `mips-3.4` — MIPS.
- `mipsel-3.4` — MIPSEL.

Публикация включает десять компонентов для каждой архитектуры (30 IPK), отдельные индексы и установочные скрипты.

## ⚠️ Обратите внимание

Это тестовая версия. Отображение температуры CPU зависит от наличия соответствующего датчика на устройстве. Исправление фоновой синхронизации каталога будет дополнительно проверяться при обычной эксплуатации Beta 6.

Обновления обнаруживаются автоматически, но не устанавливаются без действия пользователя.
