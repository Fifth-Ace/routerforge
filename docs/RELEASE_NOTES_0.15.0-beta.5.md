# RouterForge 0.15.0 Beta 5

Накопительное обновление RouterForge Beta.

## Что нового

- **RouterForge Portal** — на главной странице Core появилась ссылка на браузерное расширение, официальный сайт и установку из Chrome Web Store. На роутер расширение устанавливать не нужно.
- **Мониторинг накопителей** — Storage Doctor, история событий USB / I/O / EXT4, контроль температур и предупреждения о проблемах. SMART запускается только вручную.
- **Единый интерфейс модулей** — дальнейшие улучшения Svelte 5, управления и навигации.

## Улучшения

- Доработаны DNS Router, NFQWS Manager, журналы событий и отображение состояния.
- Исправлены ошибки в интерфейсах и диагностике, выявленные при работе с Dev.

## Важно

- **DNS Router остаётся экспериментальным.** Перед изменением рабочих DNS-настроек сохраняйте конфигурацию.
- RouterForge Portal — отдельное расширение браузера; браузерная интеграция с Core будет развиваться в следующих выпусках.
- Это Beta для предварительной проверки перед Stable.
