# Модули RouterForge

Core обеспечивает единый Web UI, авторизацию, настройки, Центр приложений и доступ к установленным модулям через Unix sockets. Остальные компоненты устанавливаются независимо, по необходимости.

| Пакет | Назначение |
| --- | --- |
| `routerforge-core` | Основной интерфейс и управление платформой |
| `routerforge-dns` | DNS, DoT, DoH и диагностика резолверов |
| `routerforge-admin` | Процессы, службы, файлы, терминал и обслуживание |
| `routerforge-monitoring` | CPU, память, температура, накопители и сеть |
| `routerforge-network-tools` | Маршруты, потоки, сетевые проверки |
| `routerforge-nfqws-manager` | Управление установленным nfqws2 |
| `routerforge-antiscan-manager` | Управление установленным Antiscan |
| `routerforge-port-access-manager` | Port Knocking, SPA, защита проброшенных портов |
| `routerforge-crowdsec-manager` | Управление CrowdSec Firewall Bouncer |
| `routerforge-profiling` | Локальная диагностика производительности Core |

Состав пакетов зависит от канала и конкретного опубликованного выпуска. Новые функции сначала могут быть доступны в Beta.

Для управления сторонними программами используются их собственные установленные службы и файлы. Возможности установки, защиты и восстановления зависят от конкретного модуля и устройства.

См. [архитектуру](ARCHITECTURE.md), [установку](INSTALLATION.md) и [политику версий](VERSIONING.md).
