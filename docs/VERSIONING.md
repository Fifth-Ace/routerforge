# RouterForge Versioning Policy

RouterForge использует `MAJOR.MINOR.PATCH` и независимое версионирование компонентов.

До первого `1.0.0` версия имеет вид `0.MINOR.PATCH`.

## PATCH — третья цифра

Повышаем PATCH, когда изменение совместимо и не создаёт новый крупный продуктовый уровень:

- bug fixes;
- UI polish;
- performance/reliability fixes;
- небольшие совместимые функции;
- уточнение security/safety поведения без смены публичной архитектуры;
- документационные/release corrections.

Пример: `0.8.0 -> 0.8.1`.

## MINOR — вторая цифра

Повышаем MINOR для заметного нового функционального уровня:

- крупная новая подсистема;
- самостоятельный существенный модуль;
- значимое архитектурное изменение;
- большая новая user-facing capability;
- compatibility boundary, которую важно видеть по версии.

Пример: `0.8.1 -> 0.9.0 -> 0.10.0`.

Версии не являются десятичными числами: после `0.9.0` нормально идёт `0.10.0`.
Количество pre-1.0 MINOR-релизов не ограничено.

## 1.0.0

`1.0.0` не наступает автоматически после `0.9.x`.

Это отдельное решение о зрелости продукта: базовая архитектура/contracts, установка,
обновление, rollback/recovery, основные modules, документация и hardware validation
должны быть достаточно стабильны, чтобы RouterForge мог публично обещать устойчивый
product contract.

## Правило выбора

Если изменение находится на границе PATCH/MINOR и не создаёт новый крупный
compatibility/product boundary — выбираем PATCH.

Версия повышается только у компонентов, продуктовый код которых изменился.
Неизменённый пакет не получает косметический bump ради общего release number.

## Stable 0.9.0 example

- Core `0.8.0 -> 0.9.0`
- DNS `0.8.0 -> 0.8.1`
- Admin `0.8.0 -> 0.8.1`
- Monitoring `0.7.1 -> 0.8.0`
- Network Tools `0.8.0 -> 0.9.0`
- Profiling `0.7.1 -> 0.7.1`

## Stable 0.11.0 example

Release-level `0.11.0` — MINOR, потому что появился новый самостоятельный Antiscan Manager.

- Core `0.10.0 -> 0.10.1` — совместимый bugfix Keenetic Entware Extras / Geo Split и integration glue.
- Antiscan Manager — первый публичный Stable `0.11.0`.
- DNS `0.10.0 -> 0.10.0`.
- Admin `0.10.0 -> 0.10.0`.
- Monitoring `0.10.0 -> 0.10.0`.
- Network Tools `0.10.0 -> 0.10.0`.
- NFQWS Manager `0.10.0 -> 0.10.0`.
- Profiling `0.10.0 -> 0.10.0`.

Это намеренно: новый RouterForge release не является командой «поднять версию каждого IPK».
