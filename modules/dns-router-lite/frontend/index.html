Как заменить DNS для всей LAN

Выбери DNS по умолчанию → нажми «Сохранить и запустить DNS» → проверь готовность → нажми «Включить для LAN».

Подключать MAC-адрес отдельного устройства не нужно. Последний выбор ON/OFF сохраняется; DoH/DoT/DoQ приложений и DNS внутри VPN этим Gate не перехватываются.

Устройства и правила
Изменения здесь — черновик. Сначала сохранить, затем явно применить DNS.

      

      
MAC — не аутентификация. Нужен свежий прямой L2-сосед. DHCP даёт имя и проверку противоречий. Клиенты за NAT, VPN или другим роутером не различаются; неизвестный клиент использует общие правила.

Правила домена для устройства
Определи, какой DNS использовать для нужного сайта на конкретном устройстве.
Что такое правила домена?
Это правила, через какой DNS открывать определённые сайты. Например, youtube.com можно направить через один DNS, а остальные сайты — через общий. Для групп задаётся основной DNS, а доменные исключения настраиваются для устройств.

      

        

        
        
        
        
      

    

    

      
Приоритеты и проверка маршрута

      
1. Домен устройства → 2. DNS устройства → 3. Группа устройств → 4. Общие домены → 5. DNS по умолчанию. При включённом наследовании общие домены проверяются перед соответствующим DNS устройства/группы. Локальные зоны всегда обслуживает штатный локальный DNS.

      

      
      
Укажи устройство и домен, затем проверь маршрут. Реальный трафик не отправляется.
