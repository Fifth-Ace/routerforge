# RouterForge 0.13.0 Beta 9

Beta 9 включает исправления Port Access Manager / odin
и ранее подготовленные изменения Beta 8.

## Port Access Manager

- Исправлена потеря сообщения об ошибке активации odin
  при автоматическом обновлении интерфейса.
- Добавлена предварительная проверка цепочек NDM.
- Улучшена диагностика отказа HTTP 409 Conflict.
- Алгоритм port knocking и watchdog сохранены.
- Активация на KN-1910 требует аппаратного подтверждения.

## DNS Manager

- Добавлена задержка холодного запуска 20 секунд.
- Улучшены повторные попытки получения DNS Info.
- Добавлено автоматическое обновление устаревшего кэша.
- KN-2310 MIPSEL: cold boot и восстановление DNS Info — PASS.
- KN-1010: отдельная аппаратная проверка остаётся необходимой.

## Архитектуры

- aarch64-3.10
- mips-3.4
- mipsel-3.4

## Версии

Согласованная матрица Beta:
10 компонентов, версия 0.13.0~beta.9.

## Ограничения

Beta является тестовым каналом.
Stable не изменяется.
Роутеры автоматически не обновляются.
