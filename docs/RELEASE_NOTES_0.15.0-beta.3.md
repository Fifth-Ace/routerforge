# RouterForge 0.15.0 Beta 3

В этом обновлении мы расширили возможности DNS Router, добавили новые настройки и улучшили удобство работы с модулем.

## Что нового

### Управление IP-адресами сайтов

Если сайт использует несколько IP-адресов, DNS Router теперь позволяет выбирать, в каком порядке возвращать их устройствам.

Доступно несколько режимов: по очереди (Round-Robin), случайный порядок, выбор с учётом доступности адресов и другие варианты.

Также добавлена возможность проверять доступность IP-адресов, чтобы отдавать предпочтение работающим серверам.

### Индивидуальные настройки DNS для устройств

Теперь можно создавать группы устройств и назначать им собственные DNS-серверы и правила.

Например, разные устройства в одной сети могут использовать разные DNS-серверы в зависимости от выбранных настроек.

### Дополнительная защита DNS

Добавлены новые возможности:

- Ограничение количества DNS-запросов от одного устройства.
- Отклонение запросов типа ANY.
- Обработка DNS-ответов, содержащих заранее указанные нежелательные IP-адреса.

Все ограничения настраиваются отдельно и не включаются автоматически.

## Что улучшено

- Переработаны разделы настроек DNS Router — стало проще управлять серверами, устройствами, группами и доменными правилами.
- Улучшено отображение состояния DNS-серверов и результатов проверки их доступности.
- Доработаны журнал запросов и отображение используемого DNS-сервера.
- Исправлены ошибки интерфейса, отображения состояния модуля и восстановления его настроек после обновления.

## Важно

Новые возможности доступны в расширенных настройках и включаются по желанию пользователя. Обычный режим работы DNS остаётся без изменений.

Изменение порядка IP-адресов помогает распределять подключения, но само по себе не гарантирует переключение на другой адрес при сбое — это также зависит от приложения.

DNS Router остаётся экспериментальным модулем.

**Поддерживаемые архитектуры:** ARM64, MIPS и MIPSEL.
