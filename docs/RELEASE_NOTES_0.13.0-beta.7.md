# RouterForge 0.13.0 Beta 7

Beta 7 — обновление CrowdSec Manager. Исправления P1 и P2 прошли тесты и CI в ветке dev. Работа на конфигурации пользователя с собственным NDM hook требует отдельной проверки.

## 🔧 CrowdSec Manager

- Улучшено обнаружение пользовательских исполняемых NDM hook (`crowdsec.sh`, `001-crowdsec.sh`) и нестандартной цепочки `_CROWDSEC_CHAIN`.
- Учитываются переходы из `FORWARD` через `_NDM_FORWARD` и цепочки с правилами DROP по CrowdSec ipset.
- Для нового управляемого hook RouterForge позиция перехода вычисляется по правилам Keenetic: перед `_NDM_FORWARD`, без фиксированного номера 1 или 8.
- Перед вставкой проверяется расположение `RELATED,ESTABLISHED → ACCEPT`; при неподходящей структуре переход не вставляется наугад.
- Существующие переходы не дублируются; пользовательские hook не перезаписываются.
- В панели для статуса `NOT VERIFIED` показываются дополнительные причины, по которым полная проверка защиты не прошла.

## 📦 Поддерживаемые архитектуры

- `aarch64-3.10` — ARM64.
- `mips-3.4` — MIPS.
- `mipsel-3.4` — MIPSEL.

Релиз включает 10 компонентов для каждой архитектуры (всего 30 IPK), отдельные индексы и установочные скрипты. Для согласованного обновления пакеты получают версию `0.13.0~beta.7`.

## ⚠️ Обратите внимание

- Beta 7 — тестовая версия. Факт прохождения CI не означает аппаратную проверку каждого варианта правил firewall.
- Установка управляемого NDM hook остаётся отдельным действием с подтверждением пользователя; публикация Beta не меняет правила firewall на роутере автоматически.
- Проблема DNS Manager после холодного запуска Keenetic Giga KN-1010 ещё исследуется и **не заявляется исправленной** в Beta 7.
- Stable не изменён. Обновления автоматически обнаруживаются, но не устанавливаются без действия пользователя.
