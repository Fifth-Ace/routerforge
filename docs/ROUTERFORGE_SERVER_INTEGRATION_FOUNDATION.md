# RouterForge Server — модуль интеграции (проект)

## Источник

Независимый Linux CLI: https://github.com/Fifth-Ace/routerforge-server

На момент фиксации фундаментального контракта: stable `v1.0.0`, Ubuntu 24.04 LTS amd64 проверена upstream. Не путать Linux Server с RouterForge Core и OPKG-пакетами для Keenetic.

## P54 (этап preview)

- Существующие 11 пакетных модулей, Registry, релизные манифесты, маршрутизация и настройки устройства не меняются.

## Будущий контракт интеграции (ещё НЕ реализован)

1. Добровольная привязка конкретного сервера после верификации владения.
2. Отдельный ограниченный агент/API на Linux-стороне, исходящий защищённый канал и явные scopes — проектирование до реализации.
3. Только read-only telemetry по умолчанию, все опасные действия с точным подтверждением.
4. Секреты не пересылать и не сохранять в браузерном localStorage; нет автосканирования сети и принятия чужих серверов.
5. Независимая версия, канал обновлений и модель отзыва доверия/сертификата; никаких автоматических модификаций SSH, UFW или KeeneticOS.
6. После обкатки — Portal-агрегатор нескольких роутеров и серверов.

## Условия активации

Пока `installSupported=false`, `pairingSupported=false`, `remoteAccessSupported=false`, `apiSupported=false`. Переключать флаги только в отдельной реализации с тестами угроз и положительной авторизацией владельца.
