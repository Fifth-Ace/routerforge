# RouterForge — история выпусков

Публичные технические изменения доступны в [GitHub Releases](https://github.com/Fifth-Ace/routerforge/releases). Авторские истории выпусков доступны исключительно во вкладке «Графомания повышенной ненужности» внутри RouterForge.

| Выпуск | Основное направление |
| --- | --- |
| [Stable 1.0.0](https://github.com/Fifth-Ace/routerforge/releases/tag/routerforge-v1.0.0) | Первый стабильный релиз платформы: 11 модулей, DNS Router, Storage Doctor, syslog-ng и Svelte 5 |
| [Stable 0.14.0](https://github.com/Fifth-Ace/routerforge/releases/tag/routerforge-v0.14.0) | Предыдущий стабильный выпуск |
| [Stable 0.13.0](https://github.com/Fifth-Ace/routerforge/releases/tag/routerforge-v0.13.0) | Port Access Manager, CrowdSec Manager, NFQWS Manager, управление журналами |
| [Stable 0.12.1](https://github.com/Fifth-Ace/routerforge/releases/tag/routerforge-v0.12.1) | Исправления обновлений, независимая телеметрия Core |
| [Stable 0.12.0](https://github.com/Fifth-Ace/routerforge/releases/tag/routerforge-v0.12.0) | Развитие Центра приложений |
| [Stable 0.11.1](https://github.com/Fifth-Ace/routerforge/releases/tag/routerforge-v0.11.1) | Совместимость и исправления модулей |
| [Stable 0.11.0](https://github.com/Fifth-Ace/routerforge/releases/tag/routerforge-v0.11.0) | Antiscan Manager |
| [Stable 0.10.0](https://github.com/Fifth-Ace/routerforge/releases/tag/routerforge-v0.10.0) | NFQWS Manager |

За актуальными версиями Stable и Beta следите по бейджам в [главном README](README.md). История Beta-сборок и предыдущих релизов сохраняется в GitHub Releases.
