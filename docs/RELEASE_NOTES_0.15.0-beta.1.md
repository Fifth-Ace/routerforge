# RouterForge 0.15.0 Beta 1

## Новые возможности

### DNS Router — экспериментальный модуль (aarch64-3.10)

- Независимый DNS-сервис RouterForge с поддержкой UDP, TCP, DoT, DoH и DoQ.
- Маршрутизация DNS-запросов по доменам и независимым спискам, включая несколько списков для одного DNS-сервера.
- Основной DNS, резервные серверы, кэширование ответов и явное применение конфигурации.
- Добавление и изменение DNS без удаления идентификаторов, привязанных списков и правил.
- Проверка DNS до сохранения и запуска: разрешение адреса, IP, сертификат TLS, доступность, RTT и причины ошибок.
- Мониторинг доступности upstream, RTT и p95.
- Журнал запросов с клиентами, доменами, типами записей, назначенным и фактически использованным сервером, ответом и задержкой.
- Поддержка включаемого пользователем DNS Gate для обычных UDP/TCP-запросов локальной сети.
- Интеграция с RouterForge App Center.

## Интерфейс

- Отдельная страница управления DNS Router с редактором доменных списков.
- Компактные карточки DNS, горизонтальные действия и адаптивная компоновка.
- Отдельные результаты проверки IP, TLS и DNS-сервиса, включая ошибки.
- Обновлённый журнал запросов и отображение реальных адресов upstream.
- Унификация основных элементов оформления с RouterForge.

## Исправления

- Сохранение действующего DNS и связанных списков при редактировании upstream.
- Разделение черновой, сохранённой и применённой конфигураций.
- Восстановление состояния DNS-сервиса после перезапуска и диагностика проблем запуска.
- Уточнённая обработка IPv4/IPv6-топологии Keenetic и конфликтов собственных правил DNS-перехвата с другими компонентами.
- Расширены автоматические тесты DNS Router и интеграции с RouterForge Core.

## Совместимость и ограничения

- DNS Router включён в Beta 1 **только для aarch64-3.10**. Основные 10 компонентов RouterForge по-прежнему собираются для aarch64-3.10, mips-3.4 и mipsel-3.4.
- DNS Router остаётся экспериментальным; аппаратная совместимость с различными моделями Keenetic требует дополнительной проверки.
- DNS Gate включается только явным действием пользователя. Установка пакета не активирует перехват.
- DNS внутри VPN и защищённые DNS-соединения приложений (DoH/DoT/DoQ) не перехватываются.
- IPv6-перехват зависит от обнаруженной топологии сети.
- Основной DNS-модуль RouterForge работает независимо.
- Предыдущие Beta и Stable не изменяются.
