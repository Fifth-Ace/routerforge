Системное перенаправление выключено. Keenetic обслуживает DNS как раньше.

      

      Только br0, UDP/TCP 53. DoH/DoT приложений не перехватывается. При остановке DNS Lite или потере lease новые DNS-запросы возвращаются в Keenetic. После перезагрузки автоматическое включение отключено.

      Как настроить за минуту? Короткая инструкция
      
    
        
  1. Нажми «Добавить DNS», введи адрес и «Проверить» — защищённый сертификат проверим сами.
    2. 
        
  2. Открой DNS, добавь в его список домены (по одному на строку).
    3. 
        
  3. Выбери DNS по умолчанию и нажми «Сохранить и применить».
    4. 
        
  4. Для проверки подключи одно устройство в блоке «Запуск и подключение» и открой страницу «Журнал запросов».
    5. 
      

      
Сохранение списков само по себе не меняет DNS устройств. Подключение выполняется отдельно, с возможностью вернуть прежнее назначение.
