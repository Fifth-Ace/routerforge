Как заменить DNS для всей LAN

Выбери DNS по умолчанию → нажми «Сохранить и запустить DNS» → проверь готовность → нажми «Включить для LAN».

Подключать MAC-адрес отдельного устройства не нужно. Последний выбор ON/OFF сохраняется; DoH/DoT/DoQ приложений и DNS внутри VPN этим Gate не перехватываются.

Как настроить за минуту? Короткая инструкция
  1. Добавь DNS и нажми «Проверить адрес и сертификат».
  2. Открой его список справа и добавь домены — по одному на строку.
  3. Выбери DNS по умолчанию и нажми «Сохранить и запустить DNS».
  4. Нажми «Проверить готовность», затем «Включить для LAN». Готово — отдельное устройство подключать не нужно.

Чтобы вернуть обычный DNS Keenetic, нажми «Вернуть штатный DNS» в верхнем блоке.
