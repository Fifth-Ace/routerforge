# RouterForge 0.15.0 Beta 2

## Изменения

- DNS Router теперь включён в Beta-сборки для `aarch64-3.10`, `mips-3.4` и `mipsel-3.4`.
- Сохранены возможности DNS Router: UDP/TCP/DoT/DoH/DoQ, доменные списки, основной и резервные DNS, проверка черновых upstream, мониторинг и журнал запросов.
- Пакеты DNS Router для всех трёх архитектур используют один независимый DNS-сервис и одинаковую версию `0.15.0~beta.2`.
- В релизный CI добавлены проверки архитектуры ELF, зависимостей, файлов сервиса и интерфейса внутри DNS Router IPK.
- Для MIPS и MIPSEL добавлена проверка запуска DNS Router Lite `--version` под QEMU до публикации.

## Совместимость и ограничения

- В полной матрице Beta теперь 11 компонентов для каждой из трёх архитектур.
- DNS Router остаётся экспериментальным модулем. Сборка и проверка под QEMU не заменяют аппаратные испытания на реальном Keenetic с MIPS/MIPSEL.
- DNS Gate включается только по явному действию пользователя. Установка не активирует перехват DNS.
- DNS внутри VPN и защищённые запросы приложений (DoH/DoT/DoQ) не перехватываются.
- Доступность IPv6-перехвата зависит от реальной топологии сети.
- Основной DNS-модуль RouterForge работает независимо.
- Предыдущая Beta 1, Stable и работающие конфигурации маршрутизаторов не изменяются публикацией.

## Сборки

- Версия выпуска: `0.15.0-beta.2`.
- Версия пакетов: `0.15.0~beta.2`.
- Архивный тег: `routerforge-v0.15.0-beta.2`.
- 33 IPK: 11 для `aarch64-3.10`, 11 для `mips-3.4` и 11 для `mipsel-3.4`.
- Публикация только после успешного полного CI и проверки матрицы пакетов.
