ПОЛИТИКИ / 01
Upstream-пулы
DNS-серверы, транспорт и явно заданные резервные цепочки.

      

        
        
        
        

          
          

          
Выбор берёт селектор из ndnproxy; локальный порт не сохраняется. Это не проверка интернет-маршрута или шифрования. Для работы нужен отдельный --native-bridge-experimental.

          
System — системный DNS. Имена пользовательских PolicyN появятся после ручного чтения show ip policy.

          
DNS-запрос не выполнялся. Нажми кнопку для проверки выбранного upstream.

        

        
        
        
        

      

      
      
Keenetic Native: транспорт native, адрес вида native://System/./9.9.9.9 или native://Policy0/ru/common.dot.dns.yandex.net. Выбирается текущий loopback-порт из ndnproxy, но только с явным флагом --native-bridge-experimental при старте DNS Router. Шифрование за пределами локального stubby этим режимом не доказывается, поэтому encrypted-only группы его не принимают.

      
Проверка Native Bridge подтверждает только совпадение селектора и runtime-флаг. Для PolicyN может отсутствовать default route — тогда DNS-запрос завершится отказом. Пример: Policy0 без интернета корректно остаётся заблокированной; RouterForge не меняет её маршруты.

      
Новые зашифрованные группы не допускают fallback к UDP/TCP. Для уже сохранённых групп совместимость сохраняется.

      

      

      
Нет измерений

      
Native Bridge: статус ещё не запрошен. Режим read-only; готовность привязки не означает доступный интернет.

P7 показывает, какие правила реально доступны через штатные зоны. Чтение конфигурации не применяет DNS, не запускает listener и не включает перехват.

DPR2-N / ЭКСПЕРИМЕНТ ТОЛЬКО DSTEST
Временная транзакция DNS-зон
Требует отдельного серверного флага; изменяет тестовые зоны на ограниченное время и выполняет откат.
ПОВЫШЕННЫЙ РИСК

      
Перед испытанием необходимы сохранённая конфигурация, LAN-listener, отсутствие конфликтов и явное подтверждение. Не использовать на production.

      

      
Применение запрещено до проверки текущего плана

    

    

      
DPR2-O1 / ТОЛЬКО ЧТЕНИЕ
Реестр владения DNS-зонами
Сверка собственных и чужих записей. Не удаляет и не принимает чужие настройки.

      

      
Постоянные зоны не включены

    

  


  

    

      
ДИАГНОСТИКА / READ-ONLY
Среда и ресурсы
Пассивные показатели и планы интеграции без изменения настроек Keenetic.

      

        
        
        
        
      

      
Нет измерений

    

    

      
DPR2-G / АППАРАТНАЯ СОВМЕСТИМОСТЬ
Анализ hardware evidence
Вставь отчёт read-only диагностики DSTest. Данные не сохраняются на маршрутизаторе.

      

        
        

      

      

      
Аппаратная совместимость не подтверждена

    

    
Доступные экспериментальные операции запускаются только через отдельные capability-флаги, включая --shadow-lan-experimental для LAN-listener. DNS Router не занимает порт 53 и не подменяет ndnproxy. DoT/DoH проверяют TLS-сертификаты и не используют неявный fallback.
