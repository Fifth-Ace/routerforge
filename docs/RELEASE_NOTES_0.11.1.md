# RouterForge 0.11.1

Есть особый сорт программной магии: **всё работает, кнопка работает, веб-сервер работает — и всё равно открывается не та хрень.**

Именно это случилось с Keenetic Entware Extras.

В `0.11.0` RouterForge уже перестал хоронить живой Geo Split и научился нормально видеть его состояние. Казалось бы, можно расходиться. Но у программ есть древняя религия: если баг исправлен, где-нибудь рядом обязан сидеть его двоюродный брат и ждать, пока вы расслабитесь.

## Одна кнопка. Один путь. Один лишний цирк.

Кнопка открытия Keenetic Entware Extras в Центре приложений вела сюда:

```text
http://<router>:8080/
```

Адрес совершенно настоящий. Сервер там совершенно настоящий. И именно поэтому баг особенно прекрасен.

Потому что на `/` upstream отдаёт **patched stock Keenetic WebUI**.

А собственная панель Keenetic Entware Extras находится здесь:

```text
http://<router>:8080/custom/
```

То есть между «открыли нужный модуль» и «открыли вообще другой интерфейс» стояло слово `custom` и пара слэшей.

Компьютеры — удивительные устройства. Миллиарды транзисторов, криптография, маршрутизация, виртуальные машины. А потом вся эта цивилизация спотыкается об `/custom/`.

## Что исправлено

RouterForge теперь хранит для Keenetic Entware Extras явный WebUI path:

```text
/custom/
```

И кнопка открытия ведёт именно в dashboard Keenetic Entware Extras, а не в корень nginx на `:8080`.

Никаких новых сервисов. Никаких новых модулей. Никакой архитектурной революции, которую потом приходится три страницы объяснять словами «это не баг, это новый подход».

Просто неправильный адрес стал правильным.

## Версии

Это **PATCH-hotfix**, поэтому версии двигаются только там, где реально изменился поставляемый результат:

| Компонент            | Версия     |
| -------------------- | ---------- |
| RouterForge Core     | **0.10.2** |
| DNS                  | 0.10.0     |
| Admin / Control      | 0.10.0     |
| Monitoring           | 0.10.0     |
| Network Tools        | 0.10.0     |
| NFQWS Manager        | 0.10.0     |
| Antiscan Manager     | 0.11.0     |
| Profiling            | 0.10.0     |

Сам RouterForge: **0.11.1**.

Core: **0.10.2**, потому что исправленная metadata Центра приложений поставляется вместе с Core.

Остальные пакеты не менялись — значит, их версии тоже не менялись.

Это не скромность. Это просто редкий случай, когда цифры используются для описания изменений, а не как новогодняя гирлянда.

## Итого

До:

```text
:8080/
```

После:

```text
:8080/custom/
```

Вот и весь хотфикс.

Иногда разработка — это месяц архитектуры.

А иногда ты добавляешь `/custom/`, выпускаешь новую версию и идёшь выяснять, какой ещё идеально работающий кусок системы сейчас делает не то, что от него хотели.
