# RouterForge 0.15.0 Beta 5

Новая Beta расширяет возможности DNS Router, добавляет инструменты для диагностики накопителей и системных журналов, а также делает интерфейс RouterForge удобнее.

## Что нового

**DNS Router**
- Локальный DNS с записями A, AAAA, CNAME и PTR для собственной зоны RouterForge.
- Дополнительные настройки кэширования, TTL и экспериментальный раздельный кэш для правил устройств.
- Поддержка DNS Stamp для совместимых DNSCrypt, DoH, DoT и DoQ серверов с явным IP-адресом.
- Настраиваемые входящие DoT, DoH и DoQ с обязательными клиентскими сертификатами (mTLS).
- Более подробная диагностика запросов, выбранных DNS-серверов и причин маршрутизации.

**Мониторинг накопителей**
- Storage Doctor: состояние USB-накопителей, HDD и SSD, температура дисков и история обнаруженных ошибок USB, I/O и файловой системы.
- SMART-диагностика по запросу пользователя — без автоматического пробуждения спящих дисков.

**Системные журналы**
- Управление Entware syslog-ng из веб-интерфейса: настройка источников, просмотр и экспорт журналов.
- Раздельные журналы устройств с понятными именами, хранение на USB и поддержка SMB/NAS.
- Применение настроек и подключение сетевых хранилищ — только после подтверждения.

**Центр приложений и RouterForge Portal**
- Добавлены карточки сторонних приложений **opffk** и **qWDTT Server Keenetic**: обнаружение установленного ПО, сведения о совместимости и переход к веб-панелям. Установка остаётся в режиме предварительного просмотра.
- На главной странице появилась ссылка на браузерное расширение RouterForge Portal и установку из Chrome Web Store.
- Компактные закрываемые уведомления и информация о Stable-канале для MIPS/MIPSEL.

## Улучшения и исправления

- DNS Router лучше сохраняет выбранный режим при перезагрузке Entware и восстанавливает DNS-перехват после запуска.
- Улучшены переключение обычного и расширенного режимов, расположение настроек и адаптация интерфейса DNS Router.
- Доработаны отображение состояния накопителей, сведения о журналах и навигация по истории изменений.

## Важно

- **DNS Router остаётся экспериментальным.** Сохраняйте конфигурацию перед изменением рабочих DNS-настроек.
- Защищённые входящие DNS-соединения не включаются автоматически: нужны сертификаты и явное применение настроек.
- Сторонние приложения не устанавливаются автоматически из Центра приложений.
- **RouterForge Portal** — расширение браузера, его не нужно устанавливать на роутер.

Спасибо всем, кто помогает тестировать RouterForge, сообщает об ошибках и предлагает новые приложения!
